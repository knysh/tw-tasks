## Задание (TypeScript): фильтрация и преобразование массива

### Цель

Закрепить работу с массивами в TypeScript через:

- классический цикл `for` с `if/else`;
- функции высшего порядка (`filter`, `map`) и стрелочные функции.

---

## Условие

Дан массив чисел `number[]`. Нужно реализовать **две версии** логики:

1. **Версия 1 (императивная)** — с использованием:
  - `for`
  - `if/else`
  - обычных функций.
2. **Версия 2 (декларативная)** — с использованием:
  - `filter`
  - `map`
  - стрелочных функций.

---

## Задача

Написать функцию, которая:

1. Берёт массив чисел.
2. Оставляет только **чётные** числа.
3. Каждое чётное число умножает на `10`.
4. Возвращает новый массив с результатом.

Сигнатура функции:

```ts
export function transformEvenNumbers(values: number[]): number[]
```

---

## Требования

### Версия 1 — через `for` и `if/else`

- Внутри функции `transformEvenNumbers` сначала реализуй версию на:
  - `const result: number[] = []`
  - цикл `for`
  - проверки чётности числа через `if/else`
  - добавление элементов в `result` через `push`.
- В конце верни `result`.

### Версия 2 — через `filter` и `map`

- Затем реализуй **альтернативный вариант** (можно как отдельную функцию) на основе:
  - `values.filter(...)`
  - `.map(...)`
  - стрелочных функций.
- Оба варианта должны давать **одинаковый результат** для одинакового входного массива.

---

## Примеры (ожидаемое поведение)

- `transformEvenNumbers([])` → `[]`
- `transformEvenNumbers([1, 2, 3, 4])` → `[20, 40]`
- `transformEvenNumbers([5, 7, 9])` → `[]`
- `transformEvenNumbers([0, -2, 11])` → `[0, -20]`
