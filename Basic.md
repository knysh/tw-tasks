## План обучения основам программирования (Junior QA, TypeScript / Playwright)

---

## Блок 1. Базовые понятия программирования

### Задача 1. Установка окружения

- **Задача**:
  - Установить `Node.js` (LTS), `npm`.
  - Установить IDE (`VS Code`).
  - Поставить расширения: поддержка TypeScript, форматтер (например, Prettier).
- **Критерий готовности**:
  - Выполнена команда `node -v`, `npm -v`.
  - Открыт пустой проект в VS Code.

### Задача 2. Первая программа

- **Задача**:
  - Создать папку `pet-js`.
  - Инициализировать проект `npm init -y`.
  - Создать файл `index.js`, написать `console.log("Hello, world!")`.
  - Запустить через `node index.js`.
- **Критерий готовности**:
  - Есть успешный запуск программы.

### Задача 3. Переменные и типы данных

- **Задача**:
  - Создать файл `variables.js`.
  - Объявить переменные с числами, строками, булевыми значениями, массивами, объектами.
  - Выполнить простые операции: сложение чисел, конкатенация строк, доступ к элементу массива, доступ к полю объекта.
- **Критерий готовности**:
  - Вывод всех значений в консоль.

### Задача 4. Условные операторы

- **Задача**:
  - Создать файл `conditions.js`.
  - Написать функцию `canVote(age)`, которая:
    - возвращает `"can vote"`, если `age >= 18`;
    - возвращает `"too young"`, если `age < 18`.
  - Вызвать функцию с несколькими значениями (например, 10, 18, 25) и вывести в консоль.
- **Критерий готовности**:
  - Функция корректно работает для переданных значений.

### Задача 5. Циклы

- **Задача**:
  - Создать файл `loops.js`.
  - Написать:
    - цикл `for и while`, который выводит числа от 1 до 10;
    - цикл, который пробегается по массиву строк и выводит каждую строку (например, список имён).
- **Критерий готовности**:
  - Код работает без ошибок.

## Блок 2. Функции и работа с данными

### Задача 6. Функции с параметрами и результатом

- **Задача**:
  - Создать файл `functions.js`.
  - Написать функцию `sum(a, b)`, которая возвращает сумму.
  - Написать функцию `isAdult(age)`, которая возвращает `true`/`false`.
  - Вызвать функции с разными аргументами и вывести результат.
- **Критерий готовности**:
  - Код работает без ошибок.

### Задача 7. Работа с массивами

- **Задача**:
  - Создать файл `arrays.js`.
  - Создать массив чисел.
  - Написать функции:
    - `getEvenNumbers(numbers)` — возвращает массив чётных чисел;
    - `getSum(numbers)` — возвращает сумму всех элементов.
- **Критерий готовности**:
  - Функции корректно обрабатывают массивы длиной 0, 1 и более элементов.

### Задача 8. Работа с объектами

- **Задача**:
  - Создать файл `objects.js`.
  - Определить объект `user` с полями: `name`, `age`, `email`.
  - Написать функцию `getUserDescription(user)`, которая возвращает строку `"Name: ..., Age: ..., Email: ..."`.
- **Критерий готовности**:
  - Корректная работа функции.

## Блок 3. Введение в TypeScript

### Задача 9. Настройка простого TS-проекта

- **Задача**:
  - Создать новую папку `intro-ts`.
  - Инициализировать проект: `npm init -y`.
  - Установить TypeScript: `npm install --save-dev typescript`.
  - Создать базовый `tsconfig.json`.
- **Критерий готовности**:
  - Успешный запуск `npx tsc --version`.
  - `tsconfig.json` лежит в корне проекта.

### Задача 10. Переписать простые примеры на TypeScript

- **Задача**:
  - Создать файл `basics.ts`.
  - Переписать функции `sum`, `isAdult`, `getUserDescription` с явным указанием типов параметров и возвращаемых значений.
- **Критерий готовности**:
  - Успешная компиляция без ошибок TypeScript.
  - Понимание, зачем нужны типы (раннее нахождение ошибок).

### Задача 11. Типы для массивов и объектов

- **Задача**:
  - Создать тип `User` с полями `name`, `age`, `email`.
  - Создать массив `User[]`.
  - Написать функцию `getAdultUsers(users: User[]): User[]`, возвращающую только пользователей 18+.
- **Критерий готовности**:
  - Корректная фильтрация.
  - Понимание записи `User[]` и типа `User`.

## Блок 4. Введение в автоматизацию тестирования (Playwright)

### Задача 12. Установка Playwright-проекта (скелет)

- **Задача**:
  - В существующем или новом проекте инициализировать Playwright: `npx playwright init`.
  - Запустить пример тестов: `npx playwright test`.
- **Критерий готовности**:
  - Примеры запускаются и проходят.
  - Сотрудник видит структуру проекта (папка с тестами, конфиг).

### Задача 13. Чтение простого теста

- **Задача**:
  - Открыть один из сгенерированных Playwright-тестов.
  - Письменно описать, что делает каждый логический блок: подготовка, шаги, проверки.
- **Критерий готовности**:
  - Описание отражает реальное поведение теста.
  - Сотрудник может проговорить последовательность шагов.

### Задача 14. Написание самого простого теста

- **Задача**:
  - Создать новый файл теста `example.spec.ts`.
  - Написать тест, который:
    - открывает страницу (например, демо-сайт из документации Playwright);
    - проверяет, что заголовок страницы содержит ожидаемый текст.
- **Критерий готовности**:
  - Тест проходит стабильно.
  - Понимание, что такое `test`, `expect`, `page`.

## Блок 5. Логика тестов и работа с данными

### Задача 15. Использование функций внутри тестов

- **Задача**:
  - Вынести повторяющуюся последовательность шагов (например, логин) в отдельную функцию.
  - Использовать эту функцию в 2–3 разных тестах.
- **Критерий готовности**:
  - Повторяющийся код уменьшился.
  - Понимание, что функции помогают переиспользовать логику.

### Задача 16. Простая параметризация логики

- **Задача**:
  - Создать функцию, которая принимает разные входные данные (например, логин/пароль) и возвращает результат (успех/ошибка).
  - В тестах вызвать эту функцию с разными аргументами.
- **Критерий готовности**:
  - Логика работает для разных наборов данных.
  - Видна связь между параметрами функции и поведением теста.
