**Стек:** Node.js, классы ES6, без фреймворков (как в задании 1).

---

## Цель

Закрепить:

## Часть C. Новый класс `TestSuite` (композиция)

`TestSuite` — **набор** тест-кейсов для прогона. Не наследует `TestCase`.

**Поля:**

- `name` (строка, не пустая);
- `#testCases` — приватный массив.

**Методы:**

| Метод           | Описание                                                                                                                               |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `add(testCase)` | Добавить кейс. **Нельзя** добавить со статусом `'draft'` → `throw new Error('Only ready or blocked test cases can be added to suite')` |
